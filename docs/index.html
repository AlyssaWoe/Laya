Every run, the same honest pipeline.

The orchestrator follows deterministic steps — no free-roaming agents, no untraceable delegation.

1Screen· trust boundary→ 2Retrieve· BM25 evidence→ 3Policy facts· binding→ 4Laya routes· advisory→ 5Specialist· real model→ 6Verify· independent→ 7Memory· candidate→ 8Human gate· audit chain

A failed deterministic check blocks the run before any model can talk its way out. Model output is advisory arithmetic on top of the binding facts — nothing more.
